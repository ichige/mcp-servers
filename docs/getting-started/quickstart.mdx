ようこそ！このガイドでは、FastMCPのセットアップ、最初のMCP Serverの実行、ビジュアルUIの追加、そしてPrefect Horizonへのデプロイを素早く行う方法を説明します。

まだFastMCPをインストールしていない場合は、[インストール手順](/getting-started/installation)に従ってください。

## FastMCP Serverの作成

FastMCP Serverは、Tool、Resource、およびその他のMCPコンポーネント的集合体です。Serverを作成するには、まず`FastMCP`クラスをインスタンス化します。

`my_server.py`という新しいファイルを作成し、以下のコードを追加します。

```python my_server.py
from fastmcp import FastMCP

mcp = FastMCP("My MCP Server")
```

これだけです！非常にシンプルですが、FastMCP Serverを作成できました。より面白くするために、Toolを追加してみましょう。

## Toolの追加

シンプルな挨拶を返すToolを追加するには、関数を記述し、`@mcp.tool` Decoratorを付けてServerに登録します。

```python my_server.py {5-7}
from fastmcp import FastMCP

mcp = FastMCP("My MCP Server")

@mcp.tool
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

## Serverの実行

FastMCP Serverを実行する最も簡単な方法は、`run()`メソッドを呼び出すことです。ローカルServer用の`stdio`や、リモートアクセス用の`http`など、異なるTransportを選択できます。

<CodeGroup>

```python my_server.py (stdio) {9, 10}
from fastmcp import FastMCP

mcp = FastMCP("My MCP Server")

@mcp.tool
def greet(name: str) -> str:
    return f"Hello, {name}!"

if __name__ == "__main__":
    mcp.run()
```

```python my_server.py (HTTP) {9, 10}
from fastmcp import FastMCP

mcp = FastMCP("My MCP Server")

@mcp.tool
def greet(name: str) -> str:
    return f"Hello, {name}!"

if __name__ == "__main__":
    mcp.run(transport="http", port=8000)
```

</CodeGroup>

これにより、`python my_server.py`でServerを実行できます。stdio TransportはMCP ServerをClientに接続する従来の方法であり、HTTP Transportはリモート接続を可能にします。

<Tip>
なぜ `if __name__ == "__main__":` ブロックが必要なのでしょうか？

`__main__`ブロックは、一貫性と互換性のために推奨されており、Serverファイルをスクリプトとして実行するすべてのMCP ClientでServerが機能することを保証します。FastMCP CLIのみを使用してServerを実行するユーザーは、CLIがServerオブジェクトを直接インポートするため、これを省略できます。
</Tip>

### FastMCP CLIの使用

`fastmcp run`コマンドを使用してServerを起動することもできます。FastMCP CLIはServerファイルの`__main__`ブロックを**実行しない**ことに注意してください。代わりに、Serverオブジェクトをインポートし、指定されたTransportとオプションで実行します。

たとえば、このServerをデフォルトのstdio Transportで実行するには（`mcp.run()`の呼び出し方に関係なく）、以下のコマンドを使用できます。
```bash
fastmcp run my_server.py:mcp
```

このServerをHTTP Transportで実行するには、以下のコマンドを使用できます。
```bash
fastmcp run my_server.py:mcp --transport http --port 8000
```

## Serverの呼び出し

ServerがHTTP Transportで実行されたら、FastMCP Clientや、MCPプロトコルをサポートする任意のLLM Clientを使用して接続できます。

```python my_client.py
import asyncio
from fastmcp import Client

client = Client("http://localhost:8000/mcp")

async def call_tool(name: str):
    async with client:
        result = await client.call_tool("greet", {"name": name})
        print(result)

asyncio.run(call_tool("Ford"))
```

注意点:
- FastMCP Clientは非同期であるため、Clientを実行するには`asyncio.run`を使用する必要があります。
- Clientを使用する前に、Clientコンテキスト（`async with client:`）に入る必要があります。
- 同じコンテキスト内で複数のClient呼び出しを行うことができます。

## ToolへのUIの追加

Toolは通常テキストを返しますが、任意のToolでインタラクティブなUIを返すこともできます。ToolのDecoratorに`app=True`を追加し、[Prefab](https://prefab.prefect.io)コンポーネントを返します。これにより、ホストは会話の中に直接、チャート、テーブル、フォーム、またはその他の視覚要素としてレンダリングします。これには`apps`の追加パッケージが必要です（`pip install "fastmcp[apps]"`）。

`app=True`フラグは、レンダラーとプロトコルのメタデータを自動的に接続するようFastMCPに指示します。Toolは他のMCP Toolと同様に機能し（Argumentを受け取り、結果を返します）、その結果はプレーンテキストではなく、ホストが視覚的に表示するコンポーネントツリーになります。

```python my_server.py
from prefab_ui.app import PrefabApp
from prefab_ui.components import Column, Heading, Text, Badge, Row
from fastmcp import FastMCP

mcp = FastMCP("My MCP Server")


@mcp.tool(app=True)
def greet(name: str) -> PrefabApp:
    """視覚的なカードで誰かに挨拶します。"""
    with Column(gap=4, css_class="p-6") as view:
        Heading(f"Hello, {name}!")
        with Row(gap=2, align="center"):
            Text("Status")
            Badge("Greeted", variant="success")

    return PrefabApp(view=view)
```

`fastmcp dev apps my_server.py`を使用すると、MCPホストなしでローカルでアプリToolをプレビューできます。状態管理、フォーム、チャート、Server接続のインタラクティビティを含む完全なガイドについては、[Appsの概要](/apps/overview)を参照してください。

## Prefect Horizonへのデプロイ

[Prefect Horizon](https://horizon.prefect.io)は、[Prefect](https://www.prefect.io)のFastMCPチームによって構築されたエンタープライズ向けMCPプラットフォームです。MCP Serverのマネージドホスティング、認証、アクセス制御、および可観測性を提供します。

<Info>
Horizonは**個人プロジェクトでは無料**であり、チーム向けのエンタープライズガバナンスを提供します。
</Info>

Serverをデプロイするには、[GitHubアカウント](https://github.com)が必要です。アカウントがあれば、3つのステップでServerをデプロイできます。

1. `my_server.py`ファイルをGitHubリポジトリにプッシュします。
2. GitHubアカウントで[Prefect Horizon](https://horizon.prefect.io)にサインインします。
3. リポジトリから新しいプロジェクトを作成し、Serverのエントリーポイントとして`my_server.py:mcp`を入力します。

これだけです！HorizonはServerをビルドしてデプロイし、`https://your-project.fastmcp.app/mcp`のようなURLで利用できるようにします。チャットして機能をテストしたり、MCPプロトコルをサポートする任意のLLM Clientから接続したりできます。

詳細については、[Prefect Horizonガイド](/deployment/prefect-horizon)を参照してください。
