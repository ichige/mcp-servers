**FastMCPは、MCPアプリケーションを構築するための標準フレームワークです。** [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) は、LLMをToolやデータに接続します。FastMCPは、プロトタイプから本番環境への移行に必要なすべてを提供します。機能を提供するServerの構築、任意のMCPサービスへのClientの接続、そしてToolへのインタラクティブなUIの提供が可能です。

```python {1}
from fastmcp import FastMCP

mcp = FastMCP("Demo 🚀")

@mcp.tool
def add(a: int, b: int) -> int:
    """2つの数値を加算する"""
    return a + b

if __name__ == "__main__":
    mcp.run()
```


## 迅速に開発し、形にする

[Model Context Protocol](https://modelcontextprotocol.io/) (MCP) を使用すると、エージェントにToolやデータへのアクセス権を与えることができます。しかし、効果的なMCPアプリケーション的構築は見た目以上に困難です。

FastMCPはこれらすべてを処理します。Python関数でToolを宣言するだけで、スキーマ、バリデーション、ドキュメントが自動的に生成されます。URLを使用してServerに接続すれば、Transportのネゴシエーション、認証、プロトコルのライフサイクルが自動的に管理されます。開発者はロジックに集中でき、MCPの部分はそのまま機能します。**FastMCPには、ベストプラクティスが組み込まれています。**

**これが、FastMCPがMCPを扱うための標準フレームワークである理由です。** FastMCP 1.0は、2024年に公式のMCP Python SDKに組み込まれました。現在、アクティブにメンテナンスされているこのスタンドアロンプロジェクトは1日に100万回ダウンロードされており、すべての言語におけるMCP Serverの70%が何らかのバージョンのFastMCPで稼働しています。

FastMCPには3つの柱があります。

## LLMフレンドリーなドキュメント

FastMCPのドキュメントは、複数のLLMフレンドリーな形式で利用できます。

### MCP Server

FastMCPのドキュメントにはMCP経由でアクセスできます！ServerのURLは `https://gofastmcp.com/mcp` です。

実際、FastMCPを使用してFastMCPのドキュメントを検索することができます。

```python
import asyncio
from fastmcp import Client

async def main():
    async with Client("https://gofastmcp.com/mcp") as client:
        result = await client.call_tool(
            name="SearchFastMcp",
            arguments={"query": "deploy a FastMCP server"}
        )
    print(result)

asyncio.run(main())
```

### テキスト形式

ドキュメントは [llms.txt 形式](https://llmstxt.org/) でも利用可能です。
- [llms.txt](https://gofastmcp.com/llms.txt) - すべてのドキュメントページをリストしたサイトマップ
- [llms-full.txt](https://gofastmcp.com/llms-full.txt) - 1つのファイルにまとめられたドキュメント全体（コンテキストウィンドウを超える場合があります）

URLに `.md` を追加することで、任意のページにMarkdownとしてアクセスできます。たとえば、このページは `https://gofastmcp.com/getting-started/welcome.md` になります。

また、キーボードの「Cmd+C」（Windowsの場合は「Ctrl+C」）を押すことで、任意のページをMarkdownとしてコピーすることもできます。
