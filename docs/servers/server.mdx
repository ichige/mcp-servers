 `FastMCP`クラスは、すべてのFastMCPアプリケーションの中心となる要素です。Tool、Resource、Promptのコンテナとして機能し、MCP Clientとの通信を管理し、Serverのライフサイクル全体をオーケストレーションします。

## Serverの作成

最もシンプルな形では、FastMCP Serverには名前だけが必要です。その他の設定には適切なデフォルト値が用意されています。

```python
from fastmcp import FastMCP

mcp = FastMCP("MyServer")
```

`instructions`（指示）は、Client（およびその背後にあるLLM）がServerの役割や効果的な使用方法を理解するのに役立ちます。

```python
mcp = FastMCP(
    "DataAnalysis",
    instructions="Provides tools for analyzing numerical datasets. Start with get_summary() for an overview.",
)
```

## コンポーネント

FastMCP Serverは、3種類のコンポーネントをClientに公開します。それぞれがMCPプロトコルにおいて明確な役割を果たします。

**Tool**は、アクションを実行したり外部システムにアクセスしたりするためにClientが呼び出す関数です。

```python
@mcp.tool def multiply(a: float, b: float) -> float:
    """2つの数値を掛け合わせます。"""
    return a * b
```

**Resource**は、Clientが読み取ることができるデータを公開します。呼び出し可能な関数ではなく、受動的なデータソースです。

```python
@mcp.resource("data://config")
def get_config() -> dict:
    return {"theme": "dark", "version": "1.0"}
```

**Prompt**は、LLMとのインタラクションをガイドする再利用可能なメッセージテンプレートです。

```python
@mcp.prompt
def analyze_data(data_points: list[float]) -> str:
    formatted_data = ", ".join(str(point) for point in data_points)
    return f"Please analyze these data points: {formatted_data}"
```

各コンポーネントタイプの詳細なドキュメントは、[Tools](/servers/tools)、[Resources](/servers/resources)（[Resource Templates](/servers/resources#resource-templates)を含む）、および[Prompts](/servers/prompts)を参照してください。

## Serverの実行

`mcp.run()`を呼び出してServerを起動します。`if __name__`ガードを使用することで、Serverをサブプロセスとして起動するMCP Clientとの互換性を確保できます。

```python
from fastmcp import FastMCP

mcp = FastMCP("MyServer")

@mcp.tool
def greet(name: str) -> str:
    """ユーザーに名前で挨拶します。"""
    return f"Hello, {name}!"

if __name__ == "__main__":
    mcp.run()
```

FastMCPはいくつかのTransportをサポートしています。
- **STDIO**（デフォルト）: ローカル統合およびCLIツール用
- **HTTP**: Streamable HTTPプロトコルを使用するWebサービス用
- **SSE**: レガシーなWeb Transport（非推奨）

```python
# HTTP Transportで実行
mcp.run(transport="http", host="127.0.0.1", port=9000)
```

ServerはFastMCP CLIを使用して実行することもできます。Transportやデプロイの詳細については、[Running Your Server](/deployment/running-server)を参照してください。


## 設定リファレンス

`FastMCP`コンストラクタは、identity（アイデンティティ）、composition（構成）、behavior（動作）、handlers（ハンドラー）の4つのカテゴリに分類されるパラメータを受け入れます。

### Identity

これらのパラメータは、ServerがClientに対して自身をどのように提示するかを制御します。

<Card>
<ParamField body="name" type="str" default="FastMCP">
  Clientアプリケーションやログに表示される、人間が読めるServerの名前です。
</ParamField>

<ParamField body="instructions" type="str | None">
  このServerとの対話方法に関する説明です。Clientはこれらの指示を提示し、LLMがServerの目的や利用可能な機能を理解するのを助けます。
</ParamField>

<ParamField body="version" type="str | None">
  Serverのバージョン文字列です。指定されない場合、FastMCPライブラリのバージョンがデフォルトとして使用されます。
</ParamField>

<ParamField body="website_url" type="str | None">
  <VersionBadge version="2.13.0" />

  Serverに関する詳細情報が記載されたWebサイトのURLです。Clientアプリケーションに表示されます。
</ParamField>

<ParamField body="icons" type="list[Icon] | None">
  <VersionBadge version="2.13.0" />

  Serverのアイコン表現のリストです。詳細は[Icons](/servers/icons)を参照してください。
</ParamField>
</Card>

### Composition

これらのパラメータは、コンポーネント、ミドルウェア、プロバイダー、ライフサイクルなど、Serverを構成する要素を制御します。

<Card>
<ParamField body="tools" type="list[Tool | Callable] | None">
  Serverに登録するToolです。プログラムでToolを追加する必要がある場合、`@mcp.tool` Decoratorの代わりに使用します。
</ParamField>

<ParamField body="auth" type="OAuthProvider | TokenVerifier | None">
  HTTPベースのTransportを保護するための認証プロバイダーです。設定については[Authentication](/servers/auth/authentication)を参照してください。
</ParamField>

<ParamField body="middleware" type="list[Middleware] | None">
  Serverを通過するすべてのMCPメッセージ（双方向のリクエスト、レスポンス、通知）をインターセプトして変換する[Middleware](/servers/middleware)です。ロギング、エラーハンドリング、レート制限などの横断的な関心事に利用します。
</ParamField>

<ParamField body="providers" type="list[Provider] | None">
  Tool、Resource、Promptを動的に提供する[Providers](/servers/providers)です。プロバイダーはリクエスト時にクエリされるため、データベース、API、その他の外部ソースからコンポーネントを提供できます。
</ParamField>

<ParamField body="transforms" type="list[Transform] | None">
  <VersionBadge version="3.1.0" />

  すべてのコンポーネントに適用されるServerレベルの[transforms](/servers/transforms/transforms)です。Transformは、Tool、Resource、PromptがClientにどのように提示されるかを変更します。例えば、[search transforms](/servers/transforms/tool-search)は、大規模なカタログをオンデマンドの検索に置き換えます。
</ParamField>

<ParamField body="lifespan" type="Lifespan | AsyncContextManager | None">
  Serverの起動時および停止時に実行される、Serverレベルのセットアップおよびティアダウンロジックです。コンポーザブルなライフサイクルについては[Lifespans](/servers/lifespan)を参照してください。
</ParamField>
</Card>

### Behavior

これらのパラメータは、Serverがリクエストを処理し、Clientと通信する方法を調整します。

<Card>
<ParamField body="on_duplicate" type='Literal["warn", "error", "replace", "ignore"]' default="warn">
  重複するコンポーネント登録の処理方法です。
</ParamField>

<ParamField body="strict_input_validation" type="bool" default="False">
  <VersionBadge version="2.13.0" />

  `False`（デフォルト）の場合、FastMCPは互換性のある入力を強制変換するPydanticの柔軟なバリデーションを使用します（例: intパラメータに対する `"10"` → `10`）。`True`の場合、関数を呼び出す前に正確なJSON Schemaに対して入力を検証し、型の不一致を拒否します。詳細は[Input Validation Modes](/servers/tools#input-validation-modes)を参照してください。
</ParamField>

<ParamField body="mask_error_details" type="bool | None">
  `True`の場合、実装の詳細がClientに漏れるのを防ぐため、Tool/Resourceのレスポンスに含まれる内部エラーの詳細を一般的なメッセージに置き換えます。デフォルトは `FASTMCP_MASK_ERROR_DETAILS` 環境変数に依存します。
</ParamField>

<ParamField body="list_page_size" type="int | None" default="None">
  <VersionBadge version="3.0.0" />

  リスト操作（`tools/list`、`resources/list`など）における1ページあたりの最大アイテム数です。`None`の場合、すべての結果が単一のレスポンスで返されます。詳細は[Pagination](/servers/pagination)を参照してください。
</ParamField>

<ParamField body="tasks" type="bool | None" default="False">
  バックグラウンドタスクのサポートを有効にします。`True`の場合、ToolとResourceは `CreateTaskResult` を返すことができ、Clientが結果をポーリングする間に非同期で作業を実行できます。
</ParamField>

<ParamField body="client_log_level" type="LoggingLevel | None">
  <VersionBadge version="3.2.0" />

  `context.log()` を介してMCP Clientに送信されるメッセージのデフォルトの最小ログレベルです。設定すると、このレベル未満のメッセージは抑制されます。個々のClientは、MCPの `logging/setLevel` リクエストを使用してセッションごとにこれを上書きできます。`"debug"`, `"info"`, `"notice"`, `"warning"`, `"error"`, `"critical"`, `"alert"`, `"emergency"` のいずれかを指定します。
</ParamField>

<ParamField body="dereference_schemas" type="bool" default="True">
  複雑なPydanticモデルから生成されたJSON Schema内の `$ref` ポインタを自動的に解決（dereference）します。ほとんどのClientは `$ref` のないフラットなスキーマを必要とするため、通常は有効のままにしておく必要があります。
</ParamField>
</Card>

### Handlers and Storage

これらのパラメータは、MCPの機能に対するカスタムハンドラーと、セッション状態のための永続ストレージを提供します。

<Card>
<ParamField body="sampling_handler" type="SamplingHandler | None">
  MCPのサンプリングリクエスト（Server主導のLLM呼び出し）用のカスタムハンドラーです。詳細は[Sampling](/servers/sampling)を参照してください。
</ParamField>

<ParamField body="sampling_handler_behavior" type='Literal["always", "fallback"] | None' default="fallback">
  `"fallback"` の場合、サンプリングハンドラーはTool固有のハンドラーが存在しない場合にのみ使用されます。`"always"` の場合、このハンドラーはすべてのサンプリングリクエストに使用されます。
</ParamField>

<ParamField body="session_state_store" type="AsyncKeyValue | None">
  リクエスト間で維持されるセッション状態のための永続的なKey-Valueストアです。デフォルトはインメモリストアです。Serverの再起動をまたいで永続化するには、カスタム実装を提供してください。
</ParamField>
</Card>


## タグベースのフィルタリング

<VersionBadge version="2.8.0" />

タグを使用すると、コンポーネントを分類し、選択的に公開することができます。これは、環境やユーザータイプに応じてServerの異なるビューを作成するのに役立ちます。

```python
@mcp.tool(tags={"public", "utility"})
def public_tool() -> str:
    return "This tool is public"

@mcp.tool(tags={"internal", "admin"})
def admin_tool() -> str:
    return "This tool is for admins only"
```

フィルタリングのロジックは以下の通り機能します。
- **`only=True` での有効化**: 許可リスト（allowlist）モードに切り替わります。一致するタグを少なくとも1つ持つコンポーネントのみが公開されます。
- **無効化**: 一致するタグをいずれか持つコンポーネントは非表示になります。
- **優先順位**: 後から呼び出されたものが前のものを上書きします。そのため、許可リストから除外するには、`enable` の後に `disable` を呼び出します。

<Tip>
コンポーネントが絶対に公開されないようにするには、コンポーネント自体に `enabled=False` を設定します。詳細はコンポーネント固有のドキュメントを参照してください。
</Tip>

```python
# "public"タグが付いたコンポーネントのみを公開
mcp = FastMCP()
mcp.enable(tags={"public"}, only=True)

# "internal"または"deprecated"としてタグ付けされたコンポーネントを非表示
mcp = FastMCP()
mcp.disable(tags={"internal", "deprecated"})

# 両方を組み合わせる: adminツールを表示するが、非推奨のものは非表示にする
mcp = FastMCP()
mcp.enable(tags={"admin"}, only=True).disable(tags={"deprecated"})
```

このフィルタリングはすべてのコンポーネントタイプ（Tool、Resource、Resource Template、Prompt）に適用され、リスト表示とアクセスの両方に影響します。

## カスタムルート

HTTP Transportで実行する場合、`@custom_route` Decoratorを使用して、MCPエンドポイントと並行してカスタムWebルートを追加できます。

```python
from fastmcp import FastMCP
from starlette.requests import Request
from starlette.responses import PlainTextResponse

mcp = FastMCP("MyServer")

@mcp.custom_route("/health", methods=["GET"])
async def health_check(request: Request) -> PlainTextResponse:
    return PlainTextResponse("OK")

if __name__ == "__main__":
    mcp.run(transport="http")  # http://localhost:8000/health でヘルスチェック
```

カスタムルートは、ヘルスチェック、ステータスエンドポイント、シンプルなWebhookに便利です。より複雑なWebアプリケーションの場合は、[FastAPIまたはStarletteアプリへのMCP Serverのマウント](/deployment/http#integration-with-web-frameworks)を検討してください。
